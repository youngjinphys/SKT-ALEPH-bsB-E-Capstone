## 근거 해석

**외부 자료.** APWG 2025 Q4 공식 보고서 3쪽의 2024 약376만·2025 약380만은 보고 기반 피싱 사이트 관측입니다. Okta 2025-07-01 자료는 v0의 피싱 페이지 제작·호스팅 악용 사례와 접근 제한 후속조치를 설명합니다. 두 자료에서 AI가 전체 증가를 일으켰다는 인과를 추론하지 않습니다. Oest의 과거 탐지 시차 수치는 현재 브라우저 지연·DNS 우위와 구분해 참고로 이동했습니다.

**현행 코드.** DNS 계약은 SUBTREE만 허용하고 EXACT를 묵시적으로 확대하지 않습니다. 정상 질의는 현재 설정에서 업스트림으로 전달합니다. 서명·장치·순서·만료는 정책 수신·적용 경계에서 검증합니다. 서명 오류는 새 입력을 거부하지만 기존 차단의 만료를 연장하지 않습니다. 만료 BLOCK은 에이전트 재평가로 제거하며, 안전한 정리 실패에는 중단 경로가 있습니다.

**현재 관제와 점수.** 운영자 검토·초안·갱신 worker와 서명된 노드 상태 보고가 구현되어 있습니다. 초안은 미서명·미게시입니다. 통합 HEAD의 클라우드 관제는 외부 서명 정책의 검증·게시를 같은 운영자 인증 체계에서 제공하고, 자동 수집은 미구성입니다. 게시 성공과 DNS 적용은 별개이며, 로컬 DNS 확인은 모든 LAN 단말의 보호와 다릅니다. `risk_cli --demo --json`을 현재 구현 HEAD에서 실행해 합성 R7 70점·WARN을 확인했습니다. 미리보기는 `dns_applied=false`, `published=false`, `source_authenticated=false`입니다.

**합성 DNS.** 10월 31일 `397df3f4`의 `3×4×5×2×2=240`은 격리 환경의 기대 응답 일치입니다. CNAME 공백과 정상 하위 이름 과차단을 포함합니다. 현재 HEAD의 같은 실험 재실행, 실제 탐지율, 운영 인수의 증거로 확대하지 않습니다.

**Pi CSV.** 446행 중 준비·자가시험 6행을 제외한 440행을 재집계했고, 기존 11개 arm의 수치가 선형보간과 일치함을 확인했습니다. 제외 6행에 timeout 2행이 포함됩니다. 운영 Pi 질의 240행, 공용 DNS 직접 질의 120행과 임시 캐시 80행을 구분합니다. 원시 첨부 CRLF SHA와 저장소 LF SHA의 차이는 줄바꿈이며 내용은 같습니다. 제품 :53은 캐시가 꺼져 있고 활성 차단 줄이 없었고, 약1.75ms 히트는 임시 :55353입니다. 두 분포의 중앙값 차이와 짝별 차이의 중앙값은 다르며, 어느 것도 이 실험만으로 정책의 인과적 비용을 입증하지 않습니다.

**HTTPS·확장.** 새 이름 조회의 차단과 제3자 HTTPS 안내 전환을 구분합니다. EDE 15는 RFC 8914의 차단 사유 메타정보이며 클라이언트 표시가 별도입니다. SDE는 확인 시점 RFC Editor Queue의 Internet-Draft입니다. 리졸버 경로를 바꾸면 적용 정책이 달라질 수 있고 DoH 자체만으로 우회를 판정하지 않습니다. 공공·ISP 구성은 운영 제안입니다.
