# Presentation restoration audit (2026-11-02)

Compared the historical `c922` presentation sources with the Next.js deck at the time of restoration. At restoration, the model had 22 authored slide records (13 presented, 9 archived); the current registry includes Pi DNS preliminary latency measurements with a separate unperformed controlled policy-impact evaluation (23 authored, 14 presented, 9 archived). Restoring a missing capability is distinct from reversing subsequent content and layout corrections.

## Restored omissions

- Globe: four Government / ISP / Users / Attacker role cards, surface projection, pins and leader lines. The React integration had mounted the Earth renderer but omitted the `cyber.js` card layer and `opening-orbit.js` controller. Locations are illustrative; the attacker origin is fictional. GPU fallback displays all roles in bounded static slots.
- DNS: separate query and response packets, then a direct client/web connection cue; no upstream/web traffic in the BLOCK scenario. Single traversal and manual controls preserve the explanation under reduced motion.
- Policy lifecycle: explicit single-pass normal / block / withdrawal walkthrough alongside the three manual states.
- HTTP/HTTPS and CNAME: explicit sequential emphasis with all facts remaining visible, manual steps, pause and reduced-motion handling.
- Touch navigation, explicit R walkthrough control, repeat-key guards and fullscreen error feedback are restored alongside keyboard and dialog behavior.
- Clap sensitivity (1–5, original default 3) and relative input level are available in contents; adjusting settings never starts microphone capture.
- Narrow DNS diagrams preserve the client/web and resolver/upstream columns so removing a redundant caption does not remove the visible direct connection.

## Deliberately not reverted

- Footer and bottom mini-deck: explicitly removed at the user's request.
- AI/coding benchmark correlation chart: removed because it did not establish the DNS thesis or a causal relationship with phishing growth.
- Separate precision slide: consolidated into the CNAME / SUBTREE / URL-scope discussion; sources and speaker notes remain available.
- Five-node repeated topology: simplified to policy supplier / protective DNS / client after the dedicated five-role DNS explanation.
- Root commands, timer implementation details and long commit identifiers: moved to notes / reproducibility material rather than duplicated in the main talk.
- Extra topology mascots, opening/closing shortcut buttons and a second narrative-map interface: not mechanically reintroduced into already constrained panels. Current navigation, contents and notes provide the relevant access.
- Statistics, evidence tables and references: remain static; animation should explain a process rather than imply measured network traffic.

## Verification boundaries

Historical Chromium audits covered narrow and projected viewports, keyboard/dialog behavior, reduced motion, lifecycle cleanup and scenario state. The `tests/` directory and browser test runner were removed on 2026-11-02; current CI runs TypeScript, content validation and the production build only. Those earlier screenshots and measurements do not independently verify the current deployment or physical mobile devices. GPU-unavailable checks only established fallback behavior, not hardware-accelerated globe rendering. Animated network-flow diagrams remain explanatory simulations, distinct from the separately documented Pi DNS latency observations; the presentation page does not run live DNS or TLS probes.
