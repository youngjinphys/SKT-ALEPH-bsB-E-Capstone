# Warning Portal — 독립 HTTPS 안내 (미구현)

**계획**: 자체 도메인·검증 가능한 TLS 인증서의 별도 웹페이지에서 차단 정책 범위, 차단 사유 및 오탐 신고를 안내합니다.

DNS 차단의 `NXDOMAIN` 응답은 브라우저를 이 포털로 리다이렉트하지 않습니다. 원래 피싱 HTTPS 탭의 인증서 검증·HSTS를 우회하여 HTML을 치환하는 기능은 **목표가 아닙니다**.

- `src/`: 안내 UI와 필요 시 최소 신고 접수 API
- `tests/`: 접근성, XSS·CSRF·입력 상한, 오픈 리다이렉트, TLS 테스트
- 신고는 **자동 정책 허용**이 아닌 검토 큐로 들어갑니다.

별도 관리자 대시보드는 팀 요구가 확정될 때 `apps/admin-console/`에 추가합니다. 아직 추가하지 않았습니다.

프레임워크·배포 주소·인증서·실행 명령: **미정·미구현**.
