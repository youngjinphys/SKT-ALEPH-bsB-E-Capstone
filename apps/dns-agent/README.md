# DNS Agent — 로컬 정책 집행 (미구현)

**계획**: 검증된 정책을 받아 FQDN 정규화·정확 범위/버전/만료/승인을 검증하고, 로컬 DNS 정책을 원자적으로 적용·철회하며 실패 시 마지막 정상 상태를 복원합니다.

- `src/dns_agent/`: 향후 validate/fetch/render/apply/rollback 구현 위치
- `resolver/`: Unbound RPZ 등 엔진별 **실습용** 설정과 최소 예제 위치
- `tests/`: 유효/무효 정책, EXACT·SUBTREE, A/AAAA·캐시·복원 실험

**엔진**: Unbound RPZ는 현행 권고 후보이며 팀 승인·실기 테스트 전 확정 엔진으로 표시하지 않습니다. dnsmasq의 이름 패턴과 정확 FQDN 일치를 혼동하지 않습니다.

**필수 검증**: `.test`의 기본 NXDOMAIN과 실제 정책 차단을 구별할 통제 응답 또는 정책 로그가 필요합니다. 정상 도메인·서브도메인 과차단·정책 철회·서비스 재시작을 별도로 측정합니다.

**실행 경계**: 전용 격리 VM에서만 시험합니다. 운영 공유기/게이트웨이 `resolv.conf`, 전역 방화벽 또는 공개 DNS를 직접 변경하지 않습니다. 실행 명령·서비스 권한·설정 파일은 현재 **미구현**입니다.
