# End-to-End 검증 계획 (테스트 코드 미구현)

재현 가능한 통제 실습망에서 같은 소스/정책 버전으로 관측합니다.

1. 대상 정책 적용 전 정상 응답을 확보합니다. `.test`는 원래 NXDOMAIN이 나올 수 있으므로 통제된 authoritative fixture 또는 적용 로그를 사용합니다.
2. 승인된 EXACT FQDN과 비대상·하위 이름의 A/AAAA/CNAME 응답을 비교합니다.
3. 정책 버전 갱신·만료·철회 및 negative caching 지연을 기록합니다.
4. 무효 정책과 로컬 서비스 reload 실패 후 마지막 정상 정책으로 복원되는지 측정합니다.
5. 독립 HTTPS 포털은 별도 URL로 접근되는지, 기존 악성 HTTPS 탭이 **자동 전환되지 않는지** 구분합니다.
6. 정책 서버 중단을 가정한 실험은 서버/API가 실제 구현된 경우에만 수행합니다.

각 실행은 코드 SHA, 시험 정책 SHA, 환경·명령·로그·결과·담당자 정보를 남깁니다.
