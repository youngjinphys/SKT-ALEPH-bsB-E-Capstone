# 운영 설치와 검증 순서

1. [DNS 설치·기존 설치 업그레이드](../infra/edge/README.md)에서 서버의 현재 관리 상태와 정책을 확인합니다.
2. [대시보드 정책 서버 운영](remote-policy-deployment.md)에 따라 인증·영구 저장소·서명 공개키·장치별 피드를 준비합니다.
3. 초안을 다운로드해 독립 서명하고 대시보드에서 변경 영향 확인 후 게시합니다.
4. 노드의 정책 서명 공개키·고정 피드 URL·장치 ID·fetch/apply 타이머를 확인합니다. 상태 보고 연결만으로 정책 수신이 설치되지는 않습니다.
5. 노드에서 서명된 정책 적용 시퀀스·해시·attestation을 확인하고 별도 LAN 클라이언트의 UDP/TCP 질의로 실제 영향을 검증합니다.

기존 미커밋 변경, 운영 정책, 서명키, 상태 DB와 pending journal은 보존합니다. 설치·업그레이드·정책 게시·DNS 적용·LAN 검증을 각각 기록하고 실행하지 않은 단계는 미검증으로 남깁니다. [Policy Sync 복구](policy-distribution.md)를 참고하세요.
