# 제출·증빙 기준

최종 제출은 **이 저장소의 재현 가능한 커밋과 발표 자료/테스트 증빙**을 한 묶음으로 관리합니다.

| 필수 구분 | 제출 때 확인할 것 |
| --- | --- |
| 정본 | `main`의 실제 구현 SHA, 서브모듈/외부 저장소 원본 출처 |
| 실행 | OS/버전, 의존성 잠금, 환경 예시, 실제 실행 명령 |
| 정책 | 계약 스키마/정책 JSON 예제, 승인/만료·버전·원복 로그 |
| DNS | 정상·차단·비대상 서브도메인·철회와 캐시 결과 |
| 포털 | 별도 HTTPS의 증빙과 원래 피싱 HTTPS 탭과의 차이 |
| 평가 | TP/FP/TN/FN(모델이 구현된 경우), DNS 성능/지연·샘플 수, 한계 |
| 보안 | 비밀 제거, 오탐·불완전 데이터 처리, 실패 복구 |
| 발표 | PPT, 시연 대본·백업 영상, 최종 발표 일시/장소 확인 |

**현재 저장소는 폴더·설계 문서와 구조 점검 CI만 포함**하므로 실제 서비스 실행·측정·최종 제출 준비 완료라고 표시할 수 없습니다. 실제 파일 생성 후 문서를 업데이트합니다.

**추가 제출 게이트:** 공개 저장소에 비밀값·실제 DNS 로그·운영 설정이 없는지 검토하고, 외부 IOC/이미지의 사용권·재배포 조건 및 프로젝트 소스의 라이선스 적용 여부를 팀이 확정합니다. `.gitignore`/구조 CI만으로 콘텐츠 안전성을 보증하지 않습니다.
